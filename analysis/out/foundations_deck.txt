# Foundations check, deck-level (FRA)

## 0. Diagnostics that set the design

decks_FRA.json.gz: 35646 decks. Share of decks with games_bucket == deck_games: 1.0000 (cross-tab is diagonal). Mean deck WR by games_bucket: 1: 0.383, 2: 0.378, 3: 0.398, 4: 0.526, 5: 0.578, 6: 0.611, 7: 0.678, 8: 0.719, 9: 0.723
Raw Premier game file: user_n_games_bucket takes [1, 5, 10, 50, 100, 500] over 69846 decks. Matching decks_FRA Premier decks (draft, game count) to it gives user_n_games_bucket in [100, 500] only (unmatched 0): decks_FRA holds 100+ games players only, and its `games_bucket` column is the deck's own game count.
So 'games bucket 7-9' is 'the deck played 7-9 games', which under the 7-win / 3-loss stop means a winning run (mean deck WR 0.68-0.72), and C(gb) conditions on the number of games, a function of the outcome.

Simulation (200,000 events, no skill leak, 7 wins / 3 losses stop, true logit slope 0.1): slope with all decks and no games term 0.096; all decks with C(games) 0.023; games 7-9 with C(games) 0.040. corr(skill, y) given n games: n=7: +0.29, n=8: +0.26, n=9: +0.14 (observed in decks_FRA: +0.20, +0.16, +0.04). The fall of corr(skill, y) with games, read as a skill leak in review-tests-2026-11-06 s1.1, is reproduced with no leak; conditioning on games removes about three quarters of a true slope.
Consequence: O is the original; Ia/Ib/Is60 are the test plan's 7-9 sample (reported because it was asked for, biased towards zero by construction); Ca/Cb/Cns/CA/CB are the corrected leak-free estimates and carry the verdicts. Verdict rule fixed now: basis holds if Ca and Cb keep the sign with a CI excluding 0 (or, for a null, if no effect beyond the stated bound); weakened if the point estimate falls by more than half or the CI includes 0 while O excluded it; gone if both estimates are within noise of 0; reversed if the CI excludes 0 on the other side.

Populations: two-colour, >=20 priced spells (family 1) 27196 decks; every deck (family 2) 35646; Premier 23889. Games 7-9 in family 1: 4466.
